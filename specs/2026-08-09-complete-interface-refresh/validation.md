# Complete Interface Refresh Validation

## Automated Gate

Run `npm run validate`, `npm audit --audit-level=moderate`, and `git diff --check`. Every command must pass.

## Presentation Contracts

- Remaining page headings expose their contextual eyebrow where specified and retain exactly one H1.
- Forms retain every label, hint, error association, value, action, method, and CSRF field inside the refreshed panel.
- Confirmations retain complete appointment information and privacy-safe navigation.
- Reviews, About services, locations, maps, errors, and the legacy Patch story retain all content and behavior.
- Staff metrics, filters, tables, CSV actions, moderation controls, schedules, and appointment mutations remain complete and authorized.

## Responsive and Accessibility

- At `375px`, panels, controls, tables, actions, long addresses, and map controls wrap without page-level horizontal overflow.
- At `1280px`, forms retain readable widths and operational pages use compact grids and tables.
- Focus remains visible, controls remain keyboard usable, status meaning remains textual, and decorative effects add no accessibility noise.
- Core forms, content, and staff workflows remain useful without client-side JavaScript except the existing optional map and visitor-time enhancements.

## Visual QA

- Inspect feedback, reviews, About, login, booking, confirmation, errors, dashboard, reports, and representative staff tools.
- Confirm the pages belong to the same product as the homepage and discovery journey while staff pages remain appropriately restrained.

## Definition of Done

All automated and visual gates pass, no business behavior changes, generated QA artifacts are removed, and Phase 13 is marked complete.
